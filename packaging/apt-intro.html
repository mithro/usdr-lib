Snapshot build of wavelet-lab/usdr-lib for Debian trixie, arm64 + amd64 (upstream ships bookworm and bionic packages only). Provides the uSDR host library, tools (usdr_dm_create, usdr_dm_sensors, usdr_flash), the SoapySDR module and the usdr_pcie_uram PCIe driver as DKMS. Install usdr-tools usdr-dkms soapysdr-module-usdr.
